LTE LAB VISUALIZER

Para o notebook Ubuntu, siga docs/INSTALACAO-UBUNTU.md.
O Mac atual é usado para desenvolvimento; execute o aplicativo no Ubuntu.

Abra "Abrir LTE Lab.command" para iniciar a aplicação no macOS.
Ou abra o terminal nesta pasta e execute: npm start
Também é possível executar: node main.cjs
No VS Code: F5 e selecione "Abrir LTE Lab".

Primeira instalação em outro computador:
1. Instale Node.js 22.12 ou superior.
2. Execute npm ci nesta pasta.
3. Execute npm start.
